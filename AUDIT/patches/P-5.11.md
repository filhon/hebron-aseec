# Patch — P-5.11 (Integrações Cross-App Intranet)

**Motivo:** CS-6 (integrações vivem em `packages/integrations` — o prompt atual cria 4 arquivos de
integração dentro do app; o feed-aggregator lê schemas de 3 módulos e seria import cross-app).

---

## Escopo

### ANTES

```
Conectar integrações reais. Intranet → Tarefas: decisão de reunião cria tarefa (substituir stub).
Plataforma → Intranet: KPI de alunos (stub até fase 6). Rádio → Intranet: KPI de audiência (stub
até fase 8). Feed: agregar últimos eventos de Projetos, Financeiro, Tarefas.
```

### DEPOIS

```
Conectar integrações reais via packages/integrations. Intranet → Tarefas: decisão de reunião cria
tarefa via createAutoTask (substituir stub do package). Plataforma → Intranet e Rádio → Intranet:
stubs documentados no package (fases 6 e 8). Feed: função agregadora no package
(packages/integrations/src/feed.ts) que consulta os últimos eventos de Projetos, Financeiro e
Tarefas COM o client da sessão (RLS filtra o que o usuário vê — mesmo contrato da busca de P-5.8).
```
