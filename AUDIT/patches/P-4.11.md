# Patch — P-4.11 (Integrações Cross-App Tarefas)

**Motivo:** CS-6/S1-09 — `createAutoTask` como "function pública que outros módulos chamam" não
pode viver em `apps/tarefas` (P-5.8, P-5.11 e P-7.11 mandam outros apps chamá-la; app não importa
app). Com o patch de P-4.8, ela nasce em `packages/integrations`; P-4.11 conecta os consumidores.

---

## Escopo

### ANTES

```
Conectar integrações. Projetos → Tarefas: submissão cria checklist de análise (substituir stub).
Flats → Tarefas: reserva confirmada cria tarefas de limpeza (stub — será conectado na fase 7).
Intranet → Tarefas: action items de reunião viram tarefas (stub — fase 5). Function pública
`createAutoTask` que outros módulos chamam.
```

### DEPOIS

```
Conectar integrações via packages/integrations (createAutoTask já criada em P-4.8/P-0.15).
Projetos → Tarefas: submissão cria checklist de análise (substituir o stub de
apps/projetos/src/lib/integrations/tarefas.ts por chamada real ao package). Flats → Tarefas: stub
documentado no package (fase 7). Intranet → Tarefas: stub documentado no package (fase 5). Erros:
criação de checklist na submissão é integração de leitura? NÃO — é mutação decorrente de fluxo
crítico: falha deve ser logada estruturadamente e sinalizada, não engolida (padrão S1-22/P-0.15).
```
