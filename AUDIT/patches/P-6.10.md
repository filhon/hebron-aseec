# Patch — P-6.10 (Notificações e Emails Plataforma)

**Motivo:** contradição interna — o escopo diz "Novo curso publicado (email para todos os
**matriculados**)" e o critério diz "email para todos os **usuários ativos**" (um curso novo não
tem matriculados; o executor escolheria sozinho). CS-9: e-mail em massa de novidade é comunicação
não-essencial → exige opt-in (consents de P-0.13).

---

## Escopo

### ANTES

```
Notificações: matrícula confirmada (email). Novo curso publicado (email para todos os
matriculados). Certificado emitido (email + in_app). Resposta no fórum (in_app).
```

### DEPOIS

```
Notificações: matrícula confirmada (email ao aluno — transacional). Novo curso publicado: email
para usuários ativos COM opt-in de novidades (consents de P-0.13, finalidade "newsletter/novidades")
— nunca para a base inteira sem consentimento. Certificado emitido (email + in_app —
transacional). Resposta no fórum (in_app ao autor do post).
```

## Critérios de aceite

### ANTES

```
- [ ] Matrícula: email de confirmação com link para o curso
- [ ] Novo curso: email para todos os usuários ativos
- [ ] Certificado: email com link de download + in_app
- [ ] Resposta no fórum: in_app para o autor do post original
- [ ] Lint passa
- [ ] Types passam
```

### DEPOIS

```
- [ ] Matrícula: email de confirmação com link para o curso
- [ ] Novo curso: email SOMENTE a usuários com consentimento de novidades (teste: usuário sem
      opt-in não recebe)
- [ ] Certificado: email com link + in_app
- [ ] Resposta no fórum: in_app ao autor do post original
- [ ] Lint passa · Types passam
```
