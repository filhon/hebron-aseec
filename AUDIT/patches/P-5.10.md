# Patch — P-5.10 (Notificações e Emails Intranet)

**Motivo:** o escopo duplica o "relatório financeiro mensal por email" que já é critério do P-3.10
(dois prompts donos do mesmo e-mail = dois e-mails ou dois códigos); CS-5 (briefing é cron de
P-0.14); CS-9 (anúncio urgente para "todos" deve respeitar opt-out de comunicação não-essencial? —
não: anúncio urgente é comunicação operacional interna, fica isento; deixar explícito).

---

## Escopo

### ANTES

```
Notificações: anúncio urgente (in_app + email para todos do escopo). Decisão de reunião (in_app
para diretores). Briefing (email periódico com resumo agregado: projetos, tarefas, financeiro).
Relatório financeiro mensal (email para diretores/conselheiros).
```

### DEPOIS

```
Notificações: anúncio urgente (in_app + email para todos os papéis internos — comunicação
operacional, isenta de opt-in de marketing). Decisão de reunião (in_app para diretores). Briefing:
cron em packages/jobs conforme briefing_preferences (diário/semanal), com resumo agregado
(projetos, tarefas, financeiro) — só para quem fez opt-in. O relatório financeiro mensal NÃO é
deste prompt: é o cron de P-3.10 (não duplicar template nem envio).
```

## Arquivos permitidos

```
ANTES:  - apps/intranet/src/lib/briefing-job.ts

        (demais arquivos inalterados)

```
- [ ] Anúncio urgente: notificação imediata para todos os internos
- [ ] Briefing: job Inngest com frequência configurável (diário/semanal)
- [ ] Briefing: resumo com KPIs + últimos eventos de cada módulo
- [ ] Lint passa
- [ ] Types passam
```

### DEPOIS

```

- [ ] Briefing: resumo com KPIs + últimos eventos
